This is a logbook entry. The logbook should be used to describe what we are doing, or what we have done, or what we will do. Its purpose is so that anyone can come back to this project at any point in the future and understand what it is about, what was being done and why, where all the data and the code and so on is. It is like a readme and like the Git repo's logs, but unlike the readme, it gives a running commentary on the development of the project as it happens, and unlike the Git repo's logs, it provides more context or description and explanation than just about the changes to the files.

This is all part of an effort to make this project as fully reproducible as possible.
